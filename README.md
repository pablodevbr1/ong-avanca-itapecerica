# Avança Itapecerica

**Projeto de site institucional da ONG Avança Itapecerica**

O **Avança Itapecerica** é um projeto acadêmico de desenvolvimento web que apresenta uma proposta de site institucional para uma organização voltada ao desenvolvimento social e profissional da comunidade de **Itapecerica, Minas Gerais**.

A plataforma reúne informações sobre os projetos da organização e disponibiliza uma área de cadastro para usuários interessados em participar das iniciativas.

## 📌 Sobre o projeto

A proposta do projeto é utilizar a tecnologia como ferramenta de apoio à comunidade, centralizando informações sobre oportunidades de **capacitação, desenvolvimento profissional e ações sociais**.

O site foi desenvolvido com foco em uma interface simples, organizada e responsiva, buscando proporcionar uma experiência de navegação intuitiva.

## 🚀 Funcionalidades

* Página inicial com apresentação da ONG;
* Apresentação dos projetos e iniciativas;
* Formulário de cadastro;
* Validação e tratamento de dados do formulário com JavaScript;
* Navegação entre páginas;
* Componentes de interface controlados por JavaScript;
* Organização dos arquivos por responsabilidade;
* Layout responsivo para diferentes tamanhos de tela.

## 📚 Projetos apresentados

### Capacita Itapecerica

Iniciativa voltada à **capacitação e desenvolvimento profissional**, proporcionando oportunidades de aprendizado para a comunidade.

### Banco de Talentos TrabalhaITA

Proposta de aproximação entre **profissionais em busca de oportunidades** e empresas que procuram novos talentos.

### Campanha Alimento & Dignidade

Ação social voltada à **arrecadação e distribuição de alimentos e itens essenciais** para pessoas e famílias que necessitam de apoio.

## 💻 Como executar

### Execução local

1. Clone o repositório:

```bash
git clone https://github.com/pablodevbr1/ong-avanca-itapecerica.git
```

2. Acesse a pasta:

```bash
cd ong-avanca-itapecerica
```

3. Abra o arquivo `index.html` em um navegador.

O projeto é composto por tecnologias front-end e não necessita de instalação de dependências para sua execução básica.

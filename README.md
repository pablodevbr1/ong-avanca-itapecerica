# Avança Itapecerica

Projeto desenvolvido como parte da **Primeira Experiência Prática (PEP)** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, na modalidade **EAD**, da **Cruzeiro do Sul**.

## Sobre o projeto

A proposta da atividade foi desenvolver uma página web fictícia para uma **Organização Não Governamental (ONG)**, utilizando conceitos básicos de desenvolvimento web e HTML5.

Para este projeto, foi criada a **Avança Itapecerica**, uma ONG fictícia voltada para a inclusão social, capacitação profissional, empregabilidade e ações de solidariedade na cidade de Itapecerica, Minas Gerais.

## Objetivo

O projeto tem como objetivo apresentar uma estrutura de site institucional para a ONG, permitindo ao visitante:

* Conhecer a organização;
* Conhecer sua missão, visão e valores;
* Consultar os projetos sociais desenvolvidos;
* Conhecer iniciativas de capacitação e empregabilidade;
* Realizar um cadastro para colaborar com a organização.

## Estrutura do projeto

O site é composto pelas seguintes páginas:

* **index.html** — Página inicial, com informações sobre a ONG, sua missão, visão e valores.
* **projetos.html** — Apresentação dos principais projetos sociais da organização.
* **cadastro.html** — Formulário para cadastro de colaboradores.

As imagens utilizadas no projeto estão armazenadas na pasta `assets`.

## Tecnologias utilizadas

* HTML5
* GitHub
* GitHub Pages

O projeto foi desenvolvido inicialmente utilizando apenas **HTML**, sem a utilização de CSS ou JavaScript, conforme a proposta da atividade.

## Projeto acadêmico

Este é um projeto **fictício e acadêmico**, desenvolvido exclusivamente para fins educacionais como parte da primeira experiência prática do curso de **Análise e Desenvolvimento de Sistemas EAD da Cruzeiro do Sul**.
